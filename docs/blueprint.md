# **App Name**: Eco-Fone Nepal

## Core Features:

- User Authentication: User account creation and management (login/signup) using email, Google, and Facebook.
- Detailed Product Listings: Product listings with detailed information including specifications pulled via a tool that contains images and pricing, in detail from Network bands it supports, Display's type size protection, Dimension with weight build and number of sims supported , Chip-set name with CPU specs and clock-speed and GPU detail, ram and storage with it's type, number of cameras in rear and front with features, specs of loudspeaker and mic also if able with 3.5 mm jack, special features like availability of face unlock, fingerprint, in-display fingerprint etc, lastly with battery type, capacity and it's supported charging speeds.
- AI-Enhanced Specs Comparison: AI-powered comparison tool which generates a detailed breakdown of phone features (from user specifications) from GSM Arena in order to provide additional context for a given product in the catalog.
- Advanced Product Filtering: Filtering and sorting options based on RAM, storage, display type ie. LCD, OLED, price, performance, camera and other specifications.
- Shopping Cart and Checkout: Shopping cart and checkout functionality to facilitate purchases for the signed up and logged in user.
- Responsive Design: Fully responsive design to ensure the website is accessible and functional on devices of all sizes.
- Admin Panel: Admin panel for managing inventory, adding/updating product listings, and handling orders.
